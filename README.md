# Okosodo Past Question

Offline-friendly Nigerian CBT practice app for WAEC, NECO, JAMB and other examinations.

## Current features
- Responsive CBT practice interface
- Sample practice questions, automatic scoring and explanations
- Local practice-history storage
- Progressive Web App manifest and service worker for offline app-shell caching
- Links to official examination resources

**Question authenticity:** Questions currently bundled in the app are sample practice questions, not verified official past-paper questions. They must not be labelled as official. Add official question content only when its source and permission to reproduce it have been checked.

## Run locally
Open `index.html` in a modern browser for basic practice. Service-worker installation and reliable offline caching require serving the app over HTTPS or localhost.

## Publish with GitHub Pages
1. Open repository **Settings**.
2. Choose **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then select **Save**.
5. Wait for GitHub to show the published site URL. Open it online once, then install it from your mobile browser if supported.

## Official examination resources
- WAEC e-Learning: https://www.waeconline.org.ng/e-learning/
- WAEC e-Study: https://waec.estudy.ng/
- NECO: https://neco.gov.ng/
- JAMB: https://www.jamb.gov.ng/

External websites require an internet connection. This repository is a PWA starter, not yet a native Android APK.
